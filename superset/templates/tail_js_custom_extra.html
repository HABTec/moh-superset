No URL params required. Behaviour purely by the device/screen: - Small screens (< 1024px, phones/tablets): do nothing here — the CSS media queries reflow/stack the dashboard (and the user can scroll). - Large screens (>= 1024px, laptops/monitors/TVs) VIEWING a dashboard: shrink ONLY the chart grid (.grid-content) with CSS `zoom` so the whole tab fits the screen with no vertical scroll. `zoom` (not transform:scale) keeps click targets, antd dropdowns and tooltips correctly positioned, so it stays fully interactive. Skipped automatically (no config needed): - Edit mode (the edit toolbar is present) — never rescale while editing. - Embeds & the /moh-static/tv slideshow (they run inside an iframe and do their own scaling; we must not double-fit). - Non-dashboard pages (no .grid-content → the function just no-ops). #}
